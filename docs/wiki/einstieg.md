# MRstreamdeck

**Dein Minecraft-Server auf deinen Tasten:** MRstreamdeck ist ein Plugin für das Elgato Stream Deck. Es zeigt dir, was auf einem Server mit **MRadmin** los ist - Spieler online, deine Tickets, deine Chunkloader, dein letztes Duell, und fürs Team Leistung, Warnungen und Neustarts.

## Was kann MRstreamdeck?
- **Für Spieler:** Server-Übersicht, nächster Neustart, Posteingang, eigene Tickets, eine Spielstatistik nach Wahl, Schlafabstimmung, Chunkloader an/aus, letztes Duell und Duell-Bilanz. → [Tasten für Spieler](tasten.md)
- **Fürs Team:** Leistung mit Kurve, Warnungen, Tickets des Servers, Chunkloader-Warnungen, Duelle zur Prüfung, Wartung, Warteraum, Staff-Chat, Admin-Modus, Neustart und Ankündigungen. → [Tasten fürs Team](team-tasten.md)
- **Stream Deck +:** ein Überblick auf dem Drehregler - drehen blättert durch die wichtigsten Werte.
- **Sicher:** Jede Taste zeigt nur, was du auch in der Weboberfläche siehst. Tasten mit Wirkung (Neustart, Admin-Modus, Ankündigung) brauchen einen zweiten Druck.

| Auf einen Blick | |
|---|---|
| Gerät | Elgato Stream Deck (alle Modelle, Drehregler: Stream Deck +), Stream-Deck-App 7.1 oder neuer |
| Rechner | Windows 10 oder neuer, macOS 12 oder neuer |
| Server | MRadmin mit eingeschalteter Weboberfläche und öffentlicher Adresse |
| Sprachen | Deutsch, Englisch - nach der Sprache der Stream-Deck-App |
| Status | Beta (0.x) |
