# Schnellstart

1. **Herunterladen:** [MRstreamdeck](https://mrtechnology.marcelr.at/download/mrstreamdeck/) laden und die Datei `MRstreamdeck-….streamDeckPlugin` doppelklicken - die Stream-Deck-App installiert das Plugin.
2. **Taste ziehen:** In der Stream-Deck-App unter **MRadmin** eine Taste (z.B. **Server-Übersicht**) auf dein Stream Deck ziehen.
3. **Verbinden:** In den Einstellungen der Taste die **Server-Adresse** eintragen - die Adresse der Weboberfläche deines Servers (z.B. `https://admin.meinserver.at`) - und **Mit Code verbinden** klicken. Die Taste zeigt jetzt einen Code wie `K7Q-4MX`.
4. **Bestätigen:** Im Spiel `/web link K7Q-4MX` eingeben und auf **[Verbinden]** klicken - oder **Im Browser bestätigen** und dort auf **Verbinden**. Fertig: Die Taste zeigt die Spieler online.

Die Verbindung gilt für alle MRadmin-Tasten - weitere Tasten einfach dazuziehen.

> [!TIP]
> Kein Spiel offen? In der Weboberfläche unter **Konto → Geräte → Stream Deck → Schlüssel erzeugen** einen Schlüssel machen und in den Einstellungen der Taste unter **Mit Schlüssel verbinden** einfügen. Mehr dazu unter [Verbinden](verbinden.md).

> [!NOTE]
> Der Server braucht MRadmin mit eingeschalteter Weboberfläche. Bekommst du „Am Server ausgeschaltet“ oder „Kein Recht“, frag das Team - siehe [Verbinden](verbinden.md#fürs-team-am-server).
