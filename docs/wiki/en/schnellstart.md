# Quick start

1. **Download:** get [MRstreamdeck](https://mrtechnology.marcelr.at/download/mrstreamdeck/) and double-click the file `MRstreamdeck-….streamDeckPlugin` - the Stream Deck app installs the plugin.
2. **Drag a key:** in the Stream Deck app, drag a key from **MRadmin** (e.g. **Server overview**) onto your Stream Deck.
3. **Connect:** in the settings of the key, enter the **server address** - the address of your server's web interface (e.g. `https://admin.myserver.org`) - and click **Connect with a code**. The key now shows a code like `K7Q-4MX`.
4. **Confirm:** type `/web link K7Q-4MX` in game and click **[Connect]** - or **Confirm in the browser** and click **Connect** there. Done: the key shows the players online.

The connection is shared by all MRadmin keys - simply drag more keys over.

> [!TIP]
> Game not open? In the web interface under **Account → Devices → Stream Deck → Make key**, make a key and paste it in the settings of the key under **Connect with a key**. More under [Connecting](verbinden.md).

> [!NOTE]
> The server needs MRadmin with the web interface switched on. If you get "Switched off on the server" or "No right", ask the team - see [Connecting](verbinden.md#for-the-team-on-the-server).
