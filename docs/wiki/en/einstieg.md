# MRstreamdeck

**Your Minecraft server on your keys:** MRstreamdeck is a plugin for the Elgato Stream Deck. It shows what is going on on a server with **MRadmin** - players online, your tickets, your chunk loaders, your last duel, and for the team performance, warnings and restarts.

## What can MRstreamdeck do?
- **For players:** server overview, next restart, inbox, own tickets, a game statistic of your choice, sleep vote, chunk loader on/off, last duel and duel record. → [Keys for players](tasten.md)
- **For the team:** performance with a curve, warnings, tickets of the server, chunk loader warnings, duels to review, maintenance, waiting room, staff chat, admin mode, restart and announcements. → [Keys for the team](team-tasten.md)
- **Stream Deck +:** an overview on the dial - turning goes through the most important values.
- **Safe:** every key only shows what you see in the web interface as well. Keys with an effect (restart, admin mode, announcement) need a second press.

| At a glance | |
|---|---|
| Device | Elgato Stream Deck (all models, dial: Stream Deck +), Stream Deck app 7.1 or newer |
| Computer | Windows 10 or newer, macOS 12 or newer |
| Server | MRadmin with the web interface switched on and a public address |
| Languages | German, English - after the language of the Stream Deck app |
| Status | Beta (0.x) |
